SIMPLE BANK MANAGEMENT SYSTEM (JAVA + HTML + CSS + JAVASCRIPT)

Requirements:
- JDK 17 or newer
- VS Code
- Extension Pack for Java (recommended)

RUN:
1. Extract the ZIP.
2. Open the SimpleBankManagement folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:  java --add-modules jdk.httpserver BankServer.java
5. Open: http://localhost:8080

No Maven, Spring Boot, MySQL, or extra libraries are required.
Data is saved locally in the data folder while the server runs and between restarts.

Features:
- Create account
- Deposit
- Withdraw
- Transfer between accounts
- View account balances
- View transactions
- Simple frontend

This is a student demonstration project only. It has no login or production banking security.
